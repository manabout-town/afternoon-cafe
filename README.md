# 오후세시 커피 — 「AI가 만든 티 벗기기」 실습 예제

가상의 카페 페이지로 AI가 만든 화면의 흔한 실수 10가지를 고쳐 보는 실습 저장소입니다.

## 받는 법
1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP**
2. 압축을 풀고 `before/index.html` 을 더블클릭하면 브라우저에서 열립니다
3. 책의 순서대로 고치고, 막히면 `steps/` 의 같은 번호 폴더와 비교하세요

## 폴더
| 폴더 | 내용 |
|---|---|
| before | 고치기 전 원본 |
| steps/01~10 | 장별로 고친 결과 |
| after | 완성본 |
| quickstart | 첫 10분 12줄 적용본 |
| styles | 스타일 세트 4종 |
| tailwind | Tailwind 변환판 |
| tools | AI 티 검사기 |
| rules | AI 규칙 파일 (Claude Code · Cursor · ChatGPT) |

사진: Gemini(Nano Banana 2)로 생성했습니다.
가게 이름·주소는 모두 가상입니다.
