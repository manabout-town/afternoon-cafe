앞으로 화면 코드를 만들 때는 아래 규칙을 지켜 주세요.

화면 작업 규칙 (「AI가 만든 티 벗기기」)

화면을 만들거나 고칠 때, 코드를 쓰기 전에 아래를 먼저 지킨다.

0. 스타일부터 고른다
"예쁘게"는 스타일이 아니다. 미니멀 / 에디토리얼 / 벤토 그리드 / 글래스모피즘 / 그라디언트 메시 /
다크 / 뉴모피즘 / 브루탈리즘 / 레트로·Y2K / 3D 중 업종에 맞는 하나를 골라 이름을 말하고 시작한다.
두 개 이상 섞지 않는다.

1~10. 숫자 규칙
1. 배경: #FFFFFF 순백, #000000 순검정 금지. 라이트 #F2~#F7, 다크 #08~#1F
2. 본문 글자: 14px (12~15px). 단, 입력칸(input·textarea·select)은 16px (아이폰 확대 방지)
3. 줄 간격: 본문 1.5~1.7, 큰 제목 1.1~1.2 (한글 제목은 1.1 미만 금지)
4. 자간: 본문 0 ~ -0.02em, 큰 제목 -0.02 ~ -0.04em. 작은 영문 라벨만 +0.05em
5. 폰트: 시스템 기본 폰트로 끝내지 않는다. 한글은 Pretendard, 숫자·라벨 보조로 모노 폰트
6. 글자색: 회색 여러 개를 하드코딩하지 않는다. 같은 먹색의 투명도 4단계(.92 / .68 / .60 / .38). .38은 비활성·장식 요소 전용, 정보 텍스트에는 쓰지 않는다
7. 모서리: 한 계열만. 타이트 2~8px 또는 소프트 14~32px. 섞지 않는다 (알약 버튼은 예외)
8. 간격: gap 16px 일괄 금지. 요소 안쪽 4~12px, 섹션 사이 24px 이상
9. 움직임: transition all·기본 ease 금지. 작은 반응 160ms cubic-bezier(0,0,.2,1), 큰 동작 480ms cubic-bezier(.16,1,.3,1)
10. 폭: 전체 1200~1440px, 긴 문단은 680px 이하(약 36em)

끝났다고 말하기 전에
폰 폭 320·390·430px에서 가로로 넘치는 곳이 없는지 확인한다
가능하면 AI 티 검사기(tools/ai-slop-check.js)로 점수를 확인한다
효과가 글씨를 방해하면 효과를 뺀다
